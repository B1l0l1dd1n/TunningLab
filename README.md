## 🚀 О проекте

**TuningLab** - современный интернет-магазин, специализирующийся на тюнинге двигателя. Проект представляет собой полнофункциональное веб-приложение с каталогом товаров, корзиной покупок и системой фильтрации.

### 🌟 Ключевые особенности

- **Современный дизайн** - Темная тема с градиентными акцентами
- **Полная адаптивность** - Оптимизирован для всех устройств
- **Интерактивный интерфейс** - Плавные анимации и переходы
- **Детальная информация** - Подробные характеристики тюнинговых решений
- **Умная корзина** - Сохранение состояния между сессиями

## 🛠 Технологии

### Frontend
- **HTML5** - Семантическая разметка
- **CSS3** - Современные стили и анимации
- **JavaScript (ES6+)** - Интерактивность и логика
- **Font Awesome** - Векторные иконки
- **Google Fonts** - Шрифт Inter

### JavaScript Функциональность

- Модальные окна с анимациями

- Поиск по каталогу в реальном времени

## 🚀 Быстрый старт

### Локальный запуск

1. **Скачайте проект**
   ```bash
   git clone https://github.com/your-username/tuninglab.git
   cd tuninglab
   ```

2. **Запустите локальный сервер**
   ```bash
   # Используя Python
   python -m http.server 8000
   
   # Или используя Node.js
   npx http-server
   
   # Или просто откройте index.html в браузере
   ```

3. **Откройте в браузере**
   ```
   http://localhost:8000
   ```

### Деплой на хостинг

1. **GitHub Pages**
   ```bash
   # Загрузите файлы в репозиторий
   git add .
   git commit -m "Deploy to GitHub Pages"
   git push origin main
   ```

2. **Netlify**
   - Перетащите папку проекта в Netlify
   - Или подключите GitHub репозиторий

3. **Vercel**
   ```bash
   npm install -g vercel
   vercel --prod
   ```
